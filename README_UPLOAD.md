# MLSA Laboratory GitHub Pages website

Upload `index.html` and the entire `images` folder to the root of the GitHub repository `MLSA-Lab/MLSA-Lab.github.io`. Keep the original `index.html` filename. The three new photo assets are:

- `images/lab-team.jpg`
- `images/robot-collaboration.jpg`
- `images/wearable-sensing.jpg`

The existing `images/portrait.jpg` reference is unchanged; upload that headshot separately if desired. Existing lab-member example entries are also unchanged and should be replaced before showcasing an actual roster.

The file now uses `<meta name="robots" content="index,follow">`, which allows search indexing but does not guarantee search results. Make sure Settings > Pages has a published site and the repository is public. If the site was unpublished, republish it.

Edit the HTML in GitHub using the pencil icon, commit to `main`, and refresh the site.
